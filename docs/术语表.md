# 术语表（docs/术语表.md）

> 每阶段结束更新一次，一行一个概念，格式固定：`概念 —— 一句话解释（带比喻） —— 用在哪个文件`
> 复习时只看这一页，不看代码。

## 阶段一（登录）

- JWT —— 把"我是谁"写在一张纸上并盖章，服务端验章就知道你是谁，不用每次都查库 —— 用在 `core/security.py`
- 依赖注入 —— 接口开跑前，框架先替你把这个接口需要的"工具"递进来（数据库会话、当前用户） —— 用在 `api/v1/auth.py` 的 `Depends(...)`
- Pydantic 模型 —— 进门前的安检，字段类型不对、少了必填项，直接拦在门口不让进业务代码 —— 用在 `schemas/auth.py`
- 密码哈希 —— 单向榨汁机，橘子进去出汁，汁变不回橘子；所以数据库泄露了也拿不到原密码 —— 用在注册与登录

## 阶段二（权限）

- RBAC —— 用户先挂角色，角色再挂权限；加人要改的是"谁当什么角色"，不是改代码里的 if —— 用在 `roles` 与 `permissions` 表
