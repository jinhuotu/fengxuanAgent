- 原因：11-25 的 17/17 是在纯关键词检索下跑的。之后开发环境开启了混合检索（`vector_retrieval_mode=hybrid`）。混合模式的做法是"关键词候选不过滤 + 向量候选按最高相似度的比例截断，两路各除以本路最高分后合并"（`app/rag/retrieval.py` 的 `_fuse_candidates`），全程没有绝对相似度下限。无关问题「量子纠缠拓扑绝缘体」在库里的相似度是 0.43、0.41、0.40…，而保留线是最高分的 0.5 倍即 0.21，所以每一条都留下了。
- 同一无关问题在三个评测库（md / docx / pdf 语料，见 [检索质量报告](../评测/检索质量.md)）上按模式对照，三个库结果相同：

| 模式 | 候选 | 保留 |
|---|---:|---:|
| keyword | 0 | 0 |
| vector | 15 | 5 |
| hybrid | 15 | 5 |

- 对照数据：五个相关问题的向量最高相似度为 0.58–0.71，第五名为 0.50–0.60；无关问题最高为 0.43。在这个语料上，0.5 左右的绝对下限能把两者分开。但样本只有一个语料、一道无关题，不足以据此定参数。
- 影响：选了知识库后问一个库里完全没有的问题，对话仍会带上最多 `top_k` 条不相干的"参考资料"，回答可能被带偏或出现不相干的引用。"无关问题不返回资料"这条设计在混合模式下已经不成立。
