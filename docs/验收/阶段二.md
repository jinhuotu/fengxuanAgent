## HTTP 验收清单

| 序号 | 操作 | 期望 |
|---|---|---|
| 1 | A 登录并查本人身份、权限 | `is_admin=true`、`status=active`，含 `users:create`、`users:list`、`users:disable`、`users:assign_role` |
| 2 | 查找或新建 `accept_b`、`accept_c` | 记录列表中的 ID，新建时 `is_admin=false`、`roles=[]` |
| 3 | B 登录、查用户列表、尝试给 A 追加角色 | 登录 `200/0`，两项受限请求均 `403/2001` |
| 4 | A 给 C 追加 `admin` | `200/0`，`created=true`，已绑定时 `false` |
| 5 | C 重新登录、查列表并给 B 追加 `user` | `200/0`，`created=true` |
| 6 | C 重复给 B 追加 `user` | `200/0`，`created=false` |
| 7 | C 连续两次撤销 B 的 `user` | `200/0`，首次 `removed=true`，再次 `false` |
| 8 | A 停用 B，B 用旧凭证查本人并尝试登录 | 停用 `200/0`，旧凭证 `401/1002`，登录 `403/1003` |
| 9 | A 启用 B，B 重新登录 | 两项均为 `200/0` |
| 10 | A 尝试停用自己 | `403/2003` |
| 11 | A 给 B 提交非法状态 `pending` | `422/1000` |
| 12 | A 撤销 C 的 `admin` | `200/0`，`removed=true` |
| 13 | 停用 B 和 C，回查最终状态 | 输出两人的 ID 和 `disabled` 状态 |
| 14 | 汇总 | 通过数 / 不通过数 / 未手验数。任一必过项失败退出 `1` |
