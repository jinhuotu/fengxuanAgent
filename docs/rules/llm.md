# LLM 专项规则（docs/rules/llm.md）

> **阶段三起才读。** 阶段一（登录）、阶段二（权限）里不要碰模型相关的任何东西。

1. **模型调用集中在一处**：全部走 `app/llm/client.py`。
   禁止在 service 或 api 里自己拼 HTTP 请求、自己读 API Key。

2. **提示词集中管理**：全部放 `app/llm/prompts/`，按用途一个文件。
   禁止在业务代码里拼接几十行的长字符串。

3. **每次调用必须有**：超时时间、重试次数上限、失败时的降级返回。
   禁止让一个模型请求把接口挂死。

4. **流式输出统一封装**：只用一个 SSE 工具函数，禁止每个接口各写一套。

5. **日志禁止打印完整提示词和 Key**：只记录长度、模型名、耗时、token 用量，敏感内容截断。

6. **知识库检索结果必须带原文片段和所属文档**，前端能显示"引用自哪里"。
   本项目是否做检索以 `docs/progress.md` 的阶段状态为准。

7. **能用代码判断的不要交给模型**：数值计算、权限判断、状态流转用代码写死。
   模型只负责语言理解和表达，这是为了稳定性和可调试性。

8. **模型输出必须校验**：结构化输出先做 schema 校验，解析失败要有明确报错，
   不要默认"模型一定按格式返回"。

9. **阶段三的起点是最小实现**：直接调模型 HTTP 接口 + MySQL 关键词检索。
   不引入 LangChain / LlamaIndex / 向量数据库，我说要升级才升级。
